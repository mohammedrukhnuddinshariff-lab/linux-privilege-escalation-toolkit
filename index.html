Linux Privilege Escalation Automation Toolkit

A Python-based project for identifying selected Linux configuration risks.

View Source Code

Project Overview

This toolkit automates selected Linux security checks and organizes collected evidence into JSON and HTML reports. It is designed for defensive auditing, cybersecurity education, and authorized testing.

Demo mode: the public page displays project information only. It does not connect to or scan a live Linux machine. Any sample results must not be interpreted as the current security state of a real system.

Scanner Modules

01 · System Information

Collects OS, kernel, architecture, and user context.

02 · SUID / SGID

Identifies selected files for manual permission review.

03 · File Permissions

Checks selected paths for world-writable files.

04 · Linux Capabilities

Collects available file capability information.

05 · Sudo Audit

Attempts a non-interactive review of current-user sudo rules.

06 · Systemd Services

Collects selected service configuration metadata.

07 · Cron Permissions

Checks selected cron locations for risky file permissions.

08 · Kernel Information

Records kernel details; automated CVE matching is not implemented.

Reporting and Validation

The local toolkit produces JSON reports, a unified findings report, and an HTML summary for manual review.

Findings are indicators for investigation, not proof of exploitability. Some checks have limited path coverage and may report errors or require authentication.

Test environment: Kali Linux in VirtualBox.

Safety and Limitations

  • Use the scanner only on systems you own or are authorized to audit.
  • The project is designed for detection and reporting, not exploitation.
  • Kernel CVE matching and comprehensive cron script analysis are future improvements.
  • Review evidence and validate results before making security decisions.
