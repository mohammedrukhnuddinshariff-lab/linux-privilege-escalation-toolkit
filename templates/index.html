Linux Privilege Escalation Audit Toolkit

A Python-based security auditing project that helps identify Linux configuration issues and potential privilege escalation risks through structured, detection-only checks.

Safe Demo Mode: This public website demonstrates the toolkit interface. It does not scan visitors' devices, execute exploits, or provide remote system access.

Project Features

  • Automated collection of Linux system information
  • SUID/SGID and file-permission auditing
  • Linux capabilities and sudo configuration checks
  • Systemd service and cron configuration reviews
  • Structured JSON reports and HTML reporting
  • Designed for authorized auditing and educational labs

Important Limitations

Findings are review prompts, not confirmed vulnerabilities. Results depend on scan permissions and the checks implemented. Kernel CVE matching is not currently implemented. Run the toolkit locally in an authorized test environment for system-specific results.
